# Estudos de Desenvolvimento Web I

Repositório de exercícios práticos desenvolvidos durante os estudos de **Desenvolvimento de Aplicações Web I (DAW-1)**, com foco nos fundamentos de HTML.

## Conteúdo

Os exercícios estão organizados por tema e nível de prática:

- **`01-hiperlinks-externo/`** — utilização de hiperlinks externos.
- **`02-hiperlinks-interno/`** — navegação por links dentro de uma página.
- **`03-hiperlinks-local/`** — navegação entre páginas locais, com informações sobre raças de cães e gatos.
- **`04-parágrafo-imagem-cabeçalho-hiperlinks-local/`** — prática de parágrafos, imagens, cabeçalhos e links locais.

## Tecnologias

- HTML
- Navegação entre páginas
- Organização de arquivos e imagens em diretórios

## Como visualizar os exercícios

1. Abra ou clone este repositório.
2. Entre na pasta do exercício desejado.
3. Abra o arquivo `index.html` em um navegador.
4. Explore os links para navegar entre as páginas.

## Objetivo

Praticar a estruturação de páginas web, compreender o funcionamento de hiperlinks e desenvolver familiaridade com a organização de sites em HTML.
